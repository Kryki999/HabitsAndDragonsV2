# Mocki (źródło kierunku, nie wzorzec)

Obrazki z ChatGPT, z których wyciągnięto tokeny i DNA stylu. **Wzorcem** dla nowych ekranów są renderowane [`../golden/`](../golden/) + [`../design-bible.md`](../design-bible.md). Każdy mock ma już swój golden.

| Plik | Ekran | Golden | Co bierzemy | Czego nie bierzemy |
|------|-------|--------|-------------|--------------------|
| [`home-quests.png`](home-quests.png) | Questy | `home-quests` | Winieta + szew, Crown Day panel, habit row, pills, tab bar | 3 taby, „50 goals” |
| [`hero.png`](hero.png) | Bohater | `hero` | Stos kart, profil + hex, segmented control, 2 sloty + plecak, heatmapa | 3 taby, osie statów z mocka (bierzemy 6 z kodu) |
| [`streak.png`](streak.png) | Streak | `flow-streak` | C1: promienie, wielka liczba, tydzień, `Button.flow` | Postać w całości (na razie medalion) |
| [`shop.png`](shop.png) | Sklep | `shop` | **Kierunek sklepu:** winieta NPC + dymek na górze, katalog itemów pod spodem, zakładka sprzedaży | SKU mebli, timer w sekundach, darmowy refresh |
| [`onboarding.png`](onboarding.png) | Onboarding | `onboarding-choice`, `onboarding-pick` | C2: rzędy wyboru ze stickerami, fioletowy primary, postać nad pytaniem | Jaja, zaimki, pytanie bez mówiącego NPC |

Postacie w mockach (miękki Wayfarer) **nie** są lockiem kreski. Kreska świata: [`../../art/style-kit.md`](../../art/style-kit.md).
