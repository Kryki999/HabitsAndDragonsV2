# Prompt — Gutterjack (loch Common, piwnica menelni)

> **Jeden** kadr 9:16: ekran walki / tutorial boss. Nie close-up rynku, nie stół Mentora.  
> Kit: [`style-kit.md`](style-kit.md) — załącz **tylko maga**, STYLE LOCK + SCENE.  
> Produkt: [`23`](../../23-act1-location-brainstorm.md) §B2 / §D0 · UX: tap menelni (L2) → **tylko piwnica** → Gutterjack. Po clear: parter koło + piętro kubeczki; piwnica zostaje farmą Common.  
> Hub: [`prompt-crownhaven-closeup.md`](prompt-crownhaven-closeup.md). Brak Elite.

**Nie** dokładaj placu stolicy. To nie Saltbone i nie Inkless — tu gwiazdą jest **jeden żul z imieniem**.

---

## Co jest pazurem (LOCK)

Kiedyś dobra restauracja. Teraz on **siedzi w piwnicy** i nie puszcza woli (butelka). Dreamwake w hubie, miękko, bez Ananiela.

Bossowie różnią się **siedzeniem + bronią**, nie mięśniami.

| | Gutterjack | Nie mylić z |
|--|------------|-------------|
| Siedzenie | **Beczka / skrzynia-tron** w piwnicy | Fotel Marrowa · biuro Rooka · kowadło Torrika |
| Broń | **Tulipan** = stłuczona butelka (slang miasta) | Teal naszyjnik · czerwona strzała · spojrzenie bazyliszka |
| Tell | Korek na brudnym sznurku (gówniany naszyjnik) | Gogle kowala · kapelusz kapitana |
| Ciało | Żywy człowiek, rozlany sot, dawniej „gość restauracji” | Szkielet, goblin, krasnal z kufla na rynku, większy Rook |

Załoga żuli = klimat tawerny **po** clear, nie osobny L1. Na kadrze walki: on duży; max 0–1 extra w tle (nie linia pijaków).

**Najłatwiejszy fail:** melanż / toast w piwnicy wina. On pije i trzyma teren. Nie wznosi kufla do kamery.
