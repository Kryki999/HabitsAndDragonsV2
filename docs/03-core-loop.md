# 03 — Core Loop & Cadence

> Sync ekonomii: [`06-economy-loot.md`](06-economy-loot.md) (2026-08-01).

## Z prototypu

Castle habits → XP/gold/key → D&D → Hero/Sage. Silne: zadania, kalendarz, daily cadence. Hub „obóz” **nie jest już domyślnym celem**.

## Cel (final) — szkic

### Pętla sesyjna (2–10 min)

Odhacz nawyki (zasługi) → feedback (XP/gold z diminishing + cap) → ewentualnie 1 tap: mapa / stolica / walka (darmowe CD lub klucz).

### Pętla dzienna (Finch-pattern)

1. **Pierwsze otwarcie dnia:** poranny reveal hex (wczorajszy batch). **Bez** morning gold (`06`).  
2. **Rano / dzień:** nawyki — gold/XP: pełne na **1–5**, 20% na **6–10**, potem **0**; 2×50g = klucz.  
3. **Walki:** darmowe wejście per loch (CD wg tieru) + klucze gdy timer niegotowy.  
4. **Wieczór / drugi check:** wyprawa discover? pin? beat ★? Mentor?  
5. **Reklama (opcjonalnie):** skróć CD / extra free (seed).

### Pętla tygodnia / progresji (Akt 1 ≈ 30 dni)

Awans **level/wpływ** + **aktywne dni** + chronologia Main ★ → odblokowania mapy i domu.  
Gold **nie** otwiera fabuły. Szczegóły bramek: [`06`](06-economy-loot.md).
