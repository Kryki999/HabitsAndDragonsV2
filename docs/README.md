# Habits & Dragons — Concept Bible

Ten folder to **czarno na białym** obraz finalnego produktu.

Prototyp V1 (`https://github.com/Kryki999/HabitsAndDragons`) = źródło inspiracji UX (nawyki, kalendarz, feel).  
Tu zapisujemy **koncepcję docelowej gry**: mechaniki, świat, grafika, animacje, psychologia, tech.

Aplikacja V2 (cienki scaffold) żyje osobno: [`../apps/mobile`](../apps/mobile). Biblia i kod nie mieszają się w jednym katalogu.

**Nowy w ekipie?** Zacznij od [`25-welcome.md`](25-welcome.md) — jeden plik: V1 vs V2, mechaniki, zajawka fabuły, stack i co jest otwarte.

**Rola agenta:** współzałożyciel / partner kreatywny / lekki PM — nie domyślny programista.  
Zobacz [`../AGENTS.md`](../AGENTS.md) i `.cursor/rules/co-founder-mode.mdc`.

## Jak pracujemy

1. Masz pomysł / wątpliwość → wrzucasz do czatu albo `ideas-inbox.md`.
2. Wpychamy to do właściwego pliku tematycznego (świat, silnik, art…).
3. W pliku trzy warstwy:
   - **Z prototypu** — co już działało / było obiecane
   - **Cel (final)** — jak ma być w docelowej grze
   - **Otwarte** — decyzje, konflikty, „jeszcze nie wiemy”
4. Gdy filar się ustabilizuje → aktualizujemy `00-final-picture.md` (jeden spójny obraz gry).

Kod w `apps/mobile` tylko gdy świadomie wychodzimy z trybu koncepcji (albo gdy owner każe scaffoldować).
